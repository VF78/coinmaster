# Reset / new manager gate

1. Finish or explicitly freeze the current micro-step; check agent and physical-run ledgers. No active work may be lost or silently restarted.
2. Reconcile existing Project items, archive completed board history without deleting issues/evidence; read back actual state.
3. OVERWRITE ACTIVE_TASK (<=40lines): timestamp, scope/status, task, paths/branch/HEAD, done, exact next step, tests/publication, budgets, dirty state and blockers. No appended timelines.
4. Keep stable facts in PROJECT_TRUTH; models/rules in their single files; results in immutable reports + RESEARCH_INDEX. Retire compatibility summaries to pointers.
5. Preserve user code, source/config/data hashes and unique raw results. Remove only demonstrated duplicates/scratch; do not alter frozen receipts. Record intentional dirty/untracked paths and unknown release state.
6. Commit/push restart-critical docs and verify remote ref/Project readback; record any blocker explicitly. Never deploy or restart services as part of handoff.
7. Provide NEW_MANAGER_PROMPT.md. Start a fresh chat, not a history fork. Read the small startup chain then only task-relevant evidence. Do not create a new research budget or grant trade permissions through the prompt.
