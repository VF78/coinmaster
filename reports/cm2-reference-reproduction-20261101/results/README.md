**Общий целевой результат ещё не достигнут.** Исторические5,636млнUSDC приDD51,44% относятся к исходной совместной BTC+SOL стратегии, с существенным влиянием SOL на общий капитал. Это нельзя приписывать BTC-only. В CM2 новая торговая логика SOL пока не включена: проверенные простые гипотезы раннего входа/собственного выхода не дали устойчивого результата. Изучается фактическая доходная SOL-часть эталона. Обычное закрытие BTC не будет само по себе закрывать существующий SOL; итоговое решение должно иметь собственный рыночный выход и приносить вклад после расходов.
