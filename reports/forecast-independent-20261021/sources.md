# Primary sources / bounded method decisions

- STUMPY: https://stumpy.readthedocs.io/en/latest/Tutorial_Pattern_Matching.html ; https://stumpy.readthedocs.io/en/latest/Tutorial_Multidimensional_Motif_Discovery.html ; maintainer normalization discussion https://github.com/stumpy-dev/stumpy/discussions/472 . Use known-pattern MASS analogues, disclose exact optimized sparse-library backend, independent neighbours, no claim that shape similarity proves a price forecast.
- MiniRocket: https://arxiv.org/abs/2012.08791 ; author https://github.com/angus924/minirocket ; axis discussion https://github.com/angus924/minirocket/issues/24 . Fit transform on past only;2016 features (multiple84), linear regularized learned-quantile heads. No inherited fixed-C classifier.
- RDST: https://arxiv.org/abs/2109.13514 ; https://www.aeon-toolkit.org/en/stable/api_reference/auto_generated/aeon.transformations.collection.shapelet_based.RandomDilatedShapeletTransform.html ; https://github.com/aeon-toolkit/aeon/discussions/3027 . Retain distance/argmin/occurrence features, bound shapelet count, proper classification/quantile heads; default Ridge output is not a calibrated probability.
- Chart CNN: published JKX paper https://economics.yale.edu/research/re-imagining-price-trends ; author renderer https://dachxiu.chicagobooth.edu/download/img_demo.html ; paper https://onlinelibrary.wiley.com/doi/abs/10.1111/jofi.13268 . OHLC/MA/volume images provide the representation reference. Original stock-return classification is not crypto entry/TP forecasting; our small CNN is an adaptation, not replication. No inspected author pretrained checkpoint is available.
- Calibration: https://proceedings.mlr.press/v70/guo17a.html ; https://scikit-learn.org/stable/modules/calibration.html . Separate past calibration, proper losses, actual measured coverage; no nominal probability guarantee.
- Quantiles: https://www.jmlr.org/papers/v7/meinshausen06a.html motivates conditional distributions, not adding a new fifth method. Time-series coverage caveat https://proceedings.mlr.press/v139/xu21h.html ; no conformal coverage guarantee claimed here.
- Multiple testing: https://www.davidhbailey.com/dhbpapers/backtest-prob.pdf . Small declared TRAIN search, CHECK never selects model. Historical CHECK prices have been studied before and are disclosed as such.
- Bybit source: https://bybit-exchange.github.io/docs/v5/market/kline ; official schema https://github.com/bybit-exchange/docs/blob/master/yml-folder/v5/market.yaml . Real public linear execution candles with raw responses/provenance; mark/funding tail is outside this prediction-only scope.

Forum/maintainer operational advice is not treated as evidence of profitable crypto forecasts. Prediction accuracy cannot establish trading ROI, fills or minute-extreme DD; future economics would require native Nautilus and separate scope.
