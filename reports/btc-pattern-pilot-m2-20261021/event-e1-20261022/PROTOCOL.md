# Frozen E1 protocol

PROTOCOL.json is the authoritative exact preregistration, written before scanning market data or reading query labels. Closed-hour directional change uses causal frozen sigma24 thresholds. The catalogue preserves full legs and observed corrections with separate extrema and confirmation times. The first incomplete leg and end/gap censoring stay explicit. No successful-event filter is permitted.

Four arms share queries, target definitions, eligible event pool, purge and scaler support. Phase and clock each receive 64 price samples on the same full observed physical interval; the 18-dimensional state preserves amplitude and elapsed durations. No end-of-event information enters a query.

The full 699-day catalogue precedes E1. Stage one may inspect counts and causal support only. A root GO is required before the single label/quality evaluation. E2/E3 require a separately defined E1 improvement. No forecast service, neural model, economic engine or operational action is included.
