# Primary-source review mapped to this pipeline

Reviewed 2026-10-22. This is a focused review of the implemented methods and proposed repairs, not a claim to have exhausted all publications. Papers establish methodology, not profitable BTC predictions. No fits or method changes were run for this review.

| Primary source | Relevant principle and consequence here |
|---|---|
| [Forecasting: Principles and Practice, time-series cross-validation](https://otexts.com/fpp3/tscv.html) | Forecast evaluation uses origins whose training observations precede them; multi-step horizons need corresponding evaluation. Existing expanding purged prefixes are appropriate. Repair incomplete-fold acceptance without weakening temporal separation. |
| [PyTorch saving/loading models](https://docs.pytorch.org/tutorials/beginner/saving_loading_models.html) | Best-state retention must copy parameters; evaluation requires the correct model state and evaluation mode. The audited code uses copied best state, fresh full-prefix refit and eval/inference mode; none of these is an established failure cause. |
| [PyTorch KLDivLoss](https://docs.pytorch.org/docs/stable/generated/torch.nn.KLDivLoss.html) | KL uses target probability times log-target minus log-model, with the correct support and reduction. The custom masked implementation matches independent NumPy arithmetic. Its weak market result is not explained by a reversed KL or accidental mean over all pair dimensions. |
| [Bai, Kolter, Koltun, TCN](https://arxiv.org/abs/1803.01271) | Dilated causal convolutions provide receptive-field coverage. The current TCN is causal, but its theoretical field exceeds the actual 64 bars; unused padded support is a capacity/runtime limitation, not proof of a forecast sign bug. |
| [Khosla et al., Supervised Contrastive Learning](https://arxiv.org/abs/2004.11362) | Supervision defines which examples are similar. Current future-signature KL is a custom soft-neighborhood objective, not a literal reproduction of SupCon; successful image classification does not validate this trading label distance. |
| [Yue et al., TS2Vec](https://arxiv.org/abs/2106.10466) | TS2Vec uses contextual consistency and hierarchical temporal/instance contrasts. A TCN trained with the current future-signature loss is a different method. Do not attribute this pilot's result to an unexecuted TS2Vec reproduction or assume its benchmarks ensure financial skill. |
| [Kronos paper](https://arxiv.org/html/2508.02739v1), [model card](https://huggingface.co/NeoQuasar/Kronos-small), [pinned implementation](https://github.com/shiyu-coder/Kronos/blob/67b630e67f6a18c9e9be918d9b4337c960db1e9a/model/kronos.py) | The official model normalizes each OHLCVA field and clips normalized inputs; autoregressive rollouts are its documented forecasting route. Our frozen last-state extraction plus new D/Q head is a representation probe. API compatibility passed, but this is not a reproduction of rollout-based forecasting. Pretraining symbol/date overlap remains unknown without a corpus manifest. |
| [Jiang, Kelly, Xiu, Re-Imagining Price Trends](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=3756587) | Image models can learn price-related patterns in the studied stock panels. That evidence does not validate this tiny 224-pixel, two-panel BTC representation or its 72-hour first-passage targets. Keep a numeric control and test recency/precision explicitly before enlarging a visual model. |
| [Chernozhukov, Fernandez-Val, Galichon, noncrossing quantile curves](https://arxiv.org/abs/0704.3649) | Monotonic rearrangement is a recognized way to repair crossing quantiles. Retain both raw and projected forecasts. Sorting is not inherently an implementation bug and does not create predictive information or independently solve D/Q incompatibility. |
| [Lee et al., DeepHit](https://ojs.aaai.org/index.php/AAAI/article/view/11842) | A competing-event distribution is an established formulation for event type and first-hit timing. It motivates a coherent TP-first/SL-first/neither output, not a new execution engine. Its predictive advantage for these BTC paths remains an untested hypothesis. |
| [Gibbs and Candes, adaptive conformal inference](https://arxiv.org/abs/2106.00170), [Zaffran et al., dependent time-series intervals](https://proceedings.mlr.press/v162/zaffran22a.html) | Ordinary exchangeability-based coverage must not be claimed for overlapping financial horizons. Time-series calibration is a separate later step using only outcomes matured by the update time. Coverage can improve without direction skill, sharpness or profitability improving; it is not a substitute for the original forecast gates. |
| [Original mlfinlab concurrency implementation](https://github.com/hudson-and-thames/mlfinlab/blob/master/mlfinlab/sampling/concurrent.py) | Overlapping label lifetimes reuse returns. Count raw origins separately from disjoint paths and uncertainty blocks; preserve the full calendar while considering episode-aware batches only as a separately measured recipe change. Do not present a simple non-overlap count as an exact statistical effective sample size. |

## Resulting priorities

1. Repair actual provenance and evaluator-contract defects before interpreting new scores; no source patch has been applied by this audit.
2. Validate a full raw-path-to-forecast positive control before another market fit; the previous image/context toy is useful but not a substitute for every transformation in this chain.
3. If another model experiment is authorized, change one target/output contract with original physical units, full-history prefixes and fixed controls. The current first-event/quantile inconsistency motivates a small joint-barrier experiment more directly than a larger backbone or blind epoch search.
4. Treat image resolution, temporal pooling, dependence-aware batches, neighbor weighting and pretrained rollout forecasts as separate conditional options. Do not combine them in one unidentifiable optimization pass.
