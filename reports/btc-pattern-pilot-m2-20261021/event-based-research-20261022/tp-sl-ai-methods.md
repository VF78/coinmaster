# Event-conditioned AI methods for three targets and a stop

Research date: 2026-10-22. Scope: methodology and primary-source review only. No training, new forecast, simulation, backtest, CHECK, market API request, VPS action, or pilot was performed. Six usable source families and one excluded interview reference are listed below; they supply methods, not evidence of BTC trading skill. Existing weak/no-skill project findings are not overturned by this review.

## Recommendation

Use completed rise/fall waves plus corrections from the entire permitted `[2024-06-01, 2026-05-01)` history as event containers. At a decision time, compare only the currently observable partial event with historical prefixes available at equivalent causal landmarks. Estimate conditional future paths from those analogues first. Add one small regularized tabular distributional model only if it improves independent chronological evaluation. Try supervised shapelets or contrastive embeddings last, only for incremental value over the identical analogue/tabular system.

This hierarchy is a proposed design inference from the sources, not a published validated BTC recipe. A large number of candles or prefixes does not imply a large number of independent completed events. Two years of one asset can supply too few independent waves for reliable tail estimation or a neural representation.

## Define the target before choosing AI

Let side-adjusted future return from the actual decision price be `R(u)`, targets `0 < a1 < a2 < a3`, stop distance `b > 0`, and fixed policy horizon `H`. For each target define `tau_k = inf{u: R(u) >= a_k}` and `tau_SL = inf{u: R(u) <= -b}`.

- **Current CoinMaster Q is already MFE-before-fixed-SL, not unconditional MFE.** Per the parent research evidence, the D/TP-before-SL identity was established on 8,496 IDs; this review did not rerun it. For a fixed stop and horizon, define `Q_b = max(0, sup R(u) before min(tau_SL, H))`, retaining the established tie/horizon convention. Its full conditional CDF identifies fixed-barrier success: for a positive target `a`, `P(TP a before that SL by H | prefix) = P(Q_b >= a | prefix) = 1 - F_Qb(a- | prefix)` when conventions match. Three reported quantiles only constrain that CDF at a few points; they do not specify all target probabilities, hit times, or the monetary lifecycle of partial exits and changing stops.
- A **different target**, unconditional horizon MFE, would discard stop order: paths `0, -2, +5` and `0, +5, -2` have identical unconditional MFE=5 and MAE=2 but opposite TP=4/SL=1 first-exit outcomes. Their stop-conditioned Q values differ, so this example is not a defect found in CoinMaster's current labels. Do not attribute existing weak skill to an already corrected stop-conditioning error.
- TP1, TP2 and TP3 are nested achievements, not three mutually exclusive terminal competing risks. A four-class softmax of “TP1 / TP2 / TP3 / SL” is wrong for partial exits unless the mutually exclusive states are explicitly redefined. For fixed unchanged stop/horizon, pairwise reach-before-stop probabilities must satisfy `p1 >= p2 >= p3`.
- The first minimal version can count outcomes directly on saved analogue paths; neither DeepHit nor a learned multistate model is required. Under a static stop/horizon, the full Q distribution supplies each nested TP-before-stop probability, while direct paths retain timing and residual-position exits. If stops move after TP1/TP2, evaluate the specified stateful policy on those paths, including every partial fill and residual stop/time exit. A multistate description is useful bookkeeping; a learned multistate or competing-risk model is an optional later estimator, not a prerequisite. A single first-event CIF alone does not specify that full lifecycle.
- Choose the target/stop distances and partial weights as a finite, preregistered policy set or derive them in training only. Picking whichever barrier pair looks best after observing held-out paths is a new search and consumes evidence.
- A policy timeout at `H` is a fully observed outcome for finite-horizon trading, not a missing loss or win. Administrative data end before `H` is right-censoring. A TP-versus-SL competitor is an observed event, not ordinary independent censoring. Same-bar TP/SL order is unknown from OHLC alone: retain an ambiguity flag and conservative bounds; do not fabricate order.

These distinctions follow the first-passage framing of AFML and the CIF framing of competing-risk survival; the nested/multistate extension is the methodological application here. [AFML publisher](https://www.wiley.com/en-hk/advances-in-financial-machine-learning-p-9781119482109), [official competing-risk guide](https://scikit-survival.readthedocs.io/en/stable/user_guide/competing-risks.html).

## Proposed protocol A: conditional historical paths, with no learned representation

This is a future research protocol only, not authorization to execute it.

1. Register every causally detected wave/correction event with direction, event start, confirmation/availability time, decision landmarks, observed prefix interval and future label interval. A retrospective peak/trough is not known at its plotted timestamp: preserve its confirmation delay. Every decision must be reproducible using data then available.
2. Keep completed waves/corrections as the library containers. Make historical landmark prefixes that resemble the live partial event's observable age/progress; do not align using final duration, eventual peak or completed amplitude. Do not discard a historical prefix because its subsequent path looked messy. End-of-dataset incomplete follow-ups remain in a censoring registry rather than becoming falsely completed analogues or disappearing silently.
3. Normalize using only information available at the decision, such as prior volatility. Keep amplitude, duration, direction and regime descriptors alongside normalized shape; visual normalization alone can erase what determines barrier risk. Compare simple descriptor distance and a tightly constrained shape distance. Restrict historical library membership to events whose full required outcome was available before the simulated decision; exclude the same parent event and overlapping future paths.
4. First count weighted finite-horizon policy outcomes directly on saved analogue trajectories, preserving TP/SL ordering, partial exits and their timing. Use the existing fixed-stop Q definition when estimating that same static-stop target; use full trajectories when assessing changed stops or lifecycle cash flows. Incomplete follow-up needs an explicit censoring treatment or abstention; a survival estimator is optional, not mandatory for the complete-path first version. Report raw neighbor count, unique parent-event count, time concentration, and weight effective sample size `(sum w)^2 / sum(w^2)`; the last is not an independent-event count.
5. Publish three ordered candidate targets and a stop only as a conditional distribution/policy summary, with probability bands, support, ambiguity and abstention status. Fixed-stop Q can justify reach probabilities through its conditional CDF under matching conventions; three Q quantiles alone must not be presented as a full calibrated probability curve or a stateful policy return distribution.

Reject or abstain when causal segmentation cannot be reproduced, independent analogue support is below a preregistered precision requirement, support is concentrated in one wave/regime, barrier order is materially ambiguous, or intervals cannot distinguish the conditional forecast from an unconditional direction/volatility/horizon baseline. Do not invent a universal minimum `n`; required support depends on the intended precision, dependence and tail probability.

## Proposed protocol B: one incremental model and optional action filter

This is also a future research protocol only.

1. Freeze protocol A and the entry/side/exit policy. On a compact prefix descriptor set compare either a regularized discrete-time competing-risk model for first TP/SL, or a shallow QRF for a clearly separate fully observed quantile target. Avoid simultaneously searching model families, event definitions and barrier grids. Calibrate using an earlier calibration block only; assess quantile coverage/pinball loss separately from CIF probability reliability/Brier or proper log score. Censoring weights must be estimated inside the applicable training/calibration information boundary and must match the competing-risk estimand.
2. Use chronological train → calibration → held-out blocks across the full permitted history. Events sharing a parent wave remain grouped. Purge training outcomes whose intervals overlap the held-out evaluation interval; remove boundary feature/label overlap as dictated by actual lookbacks. In a strict forward split, do not add a ritual arbitrary embargo: specify what contamination the gap prevents. Fit scalers, distance metrics, shapes, representation, calibration and thresholds within their allowed blocks. A terminal period repeatedly inspected by earlier work is not a fresh holdout; label it development evidence until genuinely unseen evidence exists.
3. Optional meta-labeling asks whether to accept a **fixed** primary proposal under its full net-return policy. Use out-of-fold primary proposals/features where the primary is learned. Keep filter threshold fixed before held-out evaluation. Higher precision among a handful of selected trades is insufficient: compare with random filters matched for number of entries, side, market regime, exposure duration and capital/time at risk, as well as the unfiltered policy. Report net contribution and foregone winners, not only precision/AUC.
4. Only if the small model improves probability/distribution quality, add a few supervised shapelets or a small supervised contrastive encoder. Use the same downstream predictor, folds, policy and search budget so the comparison isolates representation. Treat every inspected alternative as part of the search history. Require improvements across multiple chronological blocks and independent events, with block/event uncertainty; aggregate score wins alone are inadequate.

Reject the added model/filter if improvement disappears against the conditional analogue/unconditional baseline, calibration fails in a later block, gains depend on one parent wave or intrabar-order convention, or exposure-matched random filtering explains the benefit. Reject representation learning if it does not add reproducible proper-score/calibration or policy value beyond descriptors at the same selection budget. Financial value requires separately authorized cost/funding/slippage-aware evaluation; none was run here.

## Decision consequence

The defensible next methodological artifact is an event/prefix/availability/label specification and a fixed comparison protocol, not a promise of profitable targets. A completed-event library plus live partial-event matching is coherent only when hindsight completion determines the stored container/outcome and never the live input or eligibility rule. Survival methods solve a target/censoring representation problem; shape learning solves a similarity problem. Neither supplies missing predictive information by itself.
