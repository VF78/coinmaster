## 4. Finite output: forecast targets versus an SL decision

Comparable forecast: H=72h, SL=1σ72; output D probabilities for first +1σ72 / first −1σ72 / NONE, and long/short MFE-before-stop quantiles q=.2/.5/.8 in σ72 units. These D/Q targets remain exactly unchanged.
For the requested variable SL, additionally output those three quantiles for BOTH sides at EACH SL multiplier {.75,1,1.5}, always H=72h. Thus 18 quantiles, six action rows; the SL=1 rows are the same primary values, not separate estimates.
Additionally output six SL-touch probabilities: for each side and distance {.75,1,1.5}σ72, probability the adverse excursion reaches that barrier at any point within 72h of entry. This is unconditional MAE to H, with no TP stopping, not probability that SL beats TP.
Freeze the displayed decision: take argmax D (UP=long, DOWN=short, NONE=no action; any tie => NO_TRADE); for that side choose the smallest SL distance with predicted SL-touch probability <=.25, else NO_TRADE. Select that row's q.2/.5/.8 as TP1/2/3. The .25 cutoff is an illustrative preregistered display rule, not an optimized or proven-safe threshold. A full-horizon adverse-touch probability is NOT the probability that a traded TP ladder actually stops out; partial TP execution changes exposure and is not simulated here.
Distances are fixed at t; absolute prices use actual later entry fill only through the frozen exponential mapping. SL selection is a decision, not a label called “correct SL”; no hindsight-optimal-stop classification, inferred EV or trading-policy evaluation follows.
Permit zero/tied quantiles as valid forecasts of atoms. Require finite nonnegative nondecreasing quantiles; finite D probabilities in [0,1] summing to 1 within frozen tolerance; finite SL probabilities in [0,1], nonincreasing as distance grows for each side. No sorting or repair. The displayed ladder requires strictly positive increasing TP distances; otherwise display NO_TRADE. It remains a forecast, not an executable order instruction. Probability-sum tolerance is1e-3; ordering/boundary tolerance1e-6. A quantile decrease as SL distance increases is recorded as CROSS_SL_INCOHERENT, scored without repair and reported separately; no cherry-picking its rows.
Use a fixed small tag vocabulary (compression, trend, failed_breakout, rejection, reversal, mixed, unclear); tags/rationale are descriptive secondary outputs, never evidence by themselves or a new primary target.
Return one JSON object: window_id, status, reason, D, six side/SL rows containing quantiles and SL-touch probability, tags, evidence (<=80 words). The deterministic display rule is calculated locally from the sealed output, rather than asking the model to choose or repair its answer. No future-informed edits.
