# Descriptive daily macro-context audit — no new forecast experiment

Daily context is a sensible missing scale to investigate. Saved E1 errors differ by an observable daily trend state, and several apparent lower-timeframe four-cell calibration patterns reverse after splitting by that state. This supports testing macro conditioning before making lower-timeframe local analogues more elaborate. It does not validate a forecast model or establish a full wave's duration.

Only existing local `minutes.npy` was memory mapped; numerical reads are bounded to genuine [2024-05-15,2026-05-01). Completed UTC D1 closes were aggregated. No CHECK-after-May1, network, VPS, new outcome target, model fit, forecast, neighbor reselection or backtest was used. All198 E1 evaluation IDs and the full699-day [2024-06-01,2026-05-01) period remain represented. All D1 query contexts use the last daily close timestamp <= query origin.

The single fixed objective reference is the existing WaveOverlay causal convention sign(close−EMA), using historical selected period34: EMA alpha2/35, seeded from the first genuine daily close. These sign episodes are **not complete growth-plus-correction waves**. Across699days there are63 observed sign runs,61 complete interior runs: median4days, p9031days, maximum72days, zero100–200days. There is a left-truncated first run and right-censored last run. This does not refute the visual observation of100–200day major full waves: a fast trend-sign definition crosses repeatedly inside a broad wave and measures a different object. No tuned ZigZag or hindsight peaks were introduced to force the observation.

The372 original catalogue events span these63 runs: median3 events/run, maximum37. The198 scored E1 events occupy35 runs, median3 events/occupied run, maximum29. These are multiple lower-timeframe observations within coarser episodes, rather than198 independent macro regimes. ## Strict-support correction and final finite-context proposal

The recursive EMA34 reference has a dependency on every genuine close since its seed;34 observations are a maturity flag, **not a finite34-day input dependency**. Under this project's strict feature-support/label-disjoint rule, declaring only34days of EMA input would be false, and using the true all-history seed dependency leaves no nonoverlapping labelled library. Consequently EMA34 remains a descriptive reference only. The earlier EMA-based candidate paragraph is superseded by the finite-context candidate below.

A single additional fixed descriptive grouping uses the sign of the **90-calendar-day log return** at the last fully closed UTC D1 close, with the physical zero boundary. No90/180 threshold competition or forecast comparison was run;180days remains descriptive context only. All198 evaluation queries have this value. Positive/negative groups do not imply that one state should be traded or excluded.

A fixed shrinkage toward eligible global prior is necessary rather than presenting small-cell frequency as a precise conditional distribution.

The final SINGLE proposed future experiment is thus a **two-cell prior conditioned on fixed90-day return sign**, with one predeclared shrinkage weight toward the common eligible full-history prior shared by all18Q/6SL. It replaces both the previous four-cell lower-timeframe proposal and EMA candidate; it does not cross90day sign with the four cells. Original lower-timeframe events remain query origins and targets. The mechanism being tested is coarse macro-state distribution change, with finite causal support that can be strictly purged. Evidence remains preliminary and macro/fold-confounded; the existing artifacts show relevance but no validated forecast gain. The owner must approve before any forecasts, fits, new labels or backtests. A100–200day full-wave detector remains undefined and untested: final retrospective cycle extrema/endpoints cannot be used as current-prefix inputs.
