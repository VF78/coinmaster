Торговый путь перенесён на данные биржи исполнения. Новый релиз установлен **неактивным**. Полный native-цикл и перезапуск прошли. Реальный START не дан. Свежий unsigned контроль установленного релиза прошёл: identity/roles/Unified/positiveUSDC,4 Info-запроса. ## Что изменилось

Один `VenueDataBinding` выводится из реальных BTC/SOL execution instrument IDs. Он задаёт историю/разогрев, D1/M1, клиент данных, C1 seed, источник событий и checkpoint identity. Обычные live и Sandbox Hyperliquid используют исключительно HL. Смешанные/неподдерживаемые биржи и несовместимый источник отвергаются; межбиржевого fallback нет. Поддержка data binding Bybit не является квалификацией Bybit live-исполнения.

Bybit остаётся явно выбранным исследовательским источником. Текущие optimizer/sequential/native_baseline непосредственно открывают Bybit minute/daily/funding файлы; они не используют изменённые warmup helpers. 14 экономических/исполнительных/исследовательских файлов побайтово совпадают с4ca0d879 — полный список/hash в `evidence/public-technical-summary.json`. Формулы/39 параметров BTC, SOL alpha/staging, C1, TP, native деньги/USDC и DP55 не оптимизировались в этой задаче.

Stock Nautilus1.231.0 HL помечает свечи временем открытия. На границе данных время преобразуется в закрытие, с сохранением фактической доступности, OHLCV и точных native Price/Quantity. Bybit повторно не сдвигается. Незакрытые/будущие, повторные, запоздавшие и неполные потоки проверяются отдельно. История и policy разделены по источнику; старые Bybit checkpoints не переименовываются, HWM/капитал не сбрасываются.

История HL исключает только начальный непрерывный неподтверждённый префикс до начала торгов; внутренние дни без сделок сохраняются. Доступный текущий разогрев достаточен; недоступный старый M1 архив не подменяется Bybit.

## Найдено и исправлено

- Обычный Sandbox и общие helper defaults неявно оставляли схему Bybit→HL. Теперь используют тот же binding; исключение Bybit явное и запрещено для real execution.
- Первый refresh нового пространства истории требовал уже существующий путь. Преждевременный strict resolve устранён; first boot проверен реальным UID.
- Required source pins дополнены границей свечей, venue binding и recovery policy. Все15 pins и94 файла пакета проверены по frozen source.
- Устаревшие тесты metadata/negative-balance/reference default приведены к действующим контрактам; продуктовые guards не ослаблены. В старом data-dependent reference probe отсутствует внешний исторический fixture — это не объявлено пройденным тестом.
- VB-A01 выявил пропущенную доставку штатного DP timer в старом native-сценарии. Исправлен именно сценарий с production callback; присваивания состояния или обхода защиты нет.
- VB-A02 достиг DP_TRIPPED_FLAT, затем упёрся в лимит времени при480 сохранениях M1. Все480 callbacks оставлены; технический лимит420с/parent435с установлен после проверки причины.

Ledger закрыт:4/6 физических попытки,2FAILED+2PASS, active0; оставшиеся2 CLOSED_NOT_TRANSFERABLE. Исходные ошибки/timeout/stdout/DB сохранены, PASS им не приписан. Закрытый старый экономический бюджет10/10 не открывался. Новых full/prefix/обучающих прогонов0.

Измеренная стоимость480 реальных native historical callbacks —131.8338с (~0.27465с/свечу), весь успешный процесс259.32с, перезапуск15.73с. Это унаследованная стоимость checkpoint при старте, а не квалификация скорости полного восьмичасового live-разогрева. Загрузка/валидация текущего HL cache реальным UID заняла14.51с; это отдельная операция. Новые позиции по-прежнему требуют свежих clocks/денег/здоровья runtime.
