# Bounded native-continuity checkpoint

This adds domain state persistence and replay for the same retained native engine/cache/account and existing minute/coherent observers. It does not reconstruct an OS-cold account/cache or recreate an observer from financial summaries. It is not a live recovery implementation.

The actual native Actor public `save()`/`load()` delegates to `on_save`/`on_load` in pinned1.231. CM2 serializes parent/targets/ordinary-intent permissions/harvest budget/finite safety cap, causal hourly aggregation, owned IDs/ACK/terminal flags, applied fill IDs, child cadence, native fee/funding attribution and liquidation lock. A namespaced BLOB/CAS table on the existing NativeEventJournal connection persists exact canonical bytes and SHA256. Identical saves do not bump revision; stale writes fail closed. No funding, fills, account balances, native fees, marks or observer samples are written or recalculated by this store.

Load requires the latest durable identical bytes and exact source/config/execution/instrument/interval identity; current native account total/free/locked/margins, actual native positions and open/inflight orders must match. Both existing observers' seed/HWM/sequence state must match without mutation. Retained audit counts and an incrementally chained SHA256 of order/fill/domain audit append events must match, which deliberately refuses a new blank report producer that would lose old evidence. The load validates everything before applying domain state. It also binds the exact current native clock and retained quote/mark/turnover signatures; it preserves these verified same-clock feed objects so the next remaining child retains identical prior-minute capacity. Advanced or missing clock/feed state fails closed. No OS-cold process inherits fabricated freshness. Historical hourly inputs retain their original availability. A failed load latches fail-closed forced drain on subsequent native quotes. Missing checkpoint rejects populated-cache startup; no automatic reconstruction or permission to resubmit missing orders.

Persistence is hooked before native submit after owned-ID registration, at ACK/fill/terminal events and material domain transitions, on stop and explicit native save. The native submit/SQLite boundary is not atomic. An interrupted/advanced cache or observer causes mismatch/UNKNOWN and refusal, not an invented rollback/retry. Replaying a checkpoint is safe only with exact native and retained observer continuity. True lost transport ACK, OS restart, external account reconstruction and concurrent native event replay are not claimed covered.

Constructor-free tests cover CAS/idempotence/conflicts/reopen/integrity, latest bytes, source/config, native cash/positions/orders, seed/HWM/sequence, retained evidence mismatch, exact parent/fees/seen-fill restoration and no partial application. Actor public save/load is actually exercised only by the connected E04 fixture after explicit authorization; unit tests do not substitute for that native proof.
