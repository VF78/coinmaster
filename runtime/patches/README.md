# Pinned Nautilus 1.231 Hyperliquid connection epoch

`nautilus-1.231.0-hl-connection-epoch.patch` changes only the Hyperliquid Rust client, its PyO3 binding, and the Action-post handler. The shared transport already advances its writer `connection_epoch` before reconnect returns to `Active`; the patch exposes that atomic value to Python. CoinMaster captures it when configuring the live report boundary and permanently revokes recovery if it changes. The stock wheel lacks the getter and fails configuration closed. Action posts use the existing writer-side no-replay send bound to initial epoch 0; read-only Info posts and subscriptions retain their original paths.

Build in an isolated Linux x86_64 CPython 3.12 builder, never in the running trader environment. The official PyPI 1.231.0 sdist pinned in `runtime/uv.lock` (SHA-256 `142dde40e77339745aa5fe6bcbb3de5624cee087f526879da00f127df077530f`) is incomplete for rebuilding: its `Cargo.toml` references `examples/tutorials` and `patches/pyo3-stub-gen`, but those directories are omitted. Use the full official `nautechsystems/nautilus_trader` `v1.231.0` tag at immutable commit `27a8e54e7ac3c57d6cbf8891f0283dfbaee97317`. Keep its `Cargo.lock` unchanged and verify both required paths before applying the tracked patch. Rust 1.97.1 is the tag minimum; the isolated build workflow pins it and adjusts only the disposable source copy because upstream `build.py` accepts `stable` or `nightly` aliases. The build frontend must run outside the source directory so local `build.py` cannot shadow the PyPA `build` module.

`.github/workflows/hl-epoch-wheel.yml` records the exact source, toolchain, patch, build, targeted Rust test and wheel hash. It creates an artifact only; it does not install or deploy a wheel. A complete run and separate disposable wheel proof are required before live approval.

Do not substitute this wheel into `runtime/.venv`, edit `uv.lock`, or remove the live pre-build guard on source tests alone. A disposable wheel install must prove the getter increments through a forced loopback disconnect/reconnect, with current socket state green again, then run the CoinMaster hidden-gap regression and connected native lifecycle tests. Recheck all submit, cancel, modify, and forced-close gates. Wheel build and wheel-level tests remain unverified until an isolated builder with the pinned toolchain and sufficient disk is available.
